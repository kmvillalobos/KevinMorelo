# Kevin Morelo Portfolio

Portafolio profesional de Kevin Andres Morelo Villalobos, orientado a perfiles de Software Engineer, Full Stack Developer, Cloud & DevOps.

## Stack

- Astro
- Tailwind CSS
- TypeScript
- Astro Icon
- Vercel-ready static build

## Secciones actualizadas

- Perfil profesional basado en la hoja de vida 2026.
- Experiencia en Cobis Topaz y Sociedad Metrológica.
- Proyecto destacado: Sociedad Biomédica.
- Stack técnico: Java, Angular, Astro, SQL, AWS, Azure DevOps, Docker, PayU, Resend.
- Enlaces a GitHub, LinkedIn, correo, Sociedad Biomédica y CV descargable.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Archivos principales

- `data/site.ts`: contenido principal del portafolio.
- `data/nav.ts`: navegación del sitio.
- `src/components`: componentes visuales.
- `public/cv-kevin-morelo.pdf`: hoja de vida descargable.

## Nota de despliegue

El valor `site.url` en `data/site.ts` está configurado como `https://kevinmorelo.vercel.app`. Cámbialo cuando definas el dominio final.
